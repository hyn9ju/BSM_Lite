# 브랜드 스타일 매트릭스 16 라이트

12개의 선택으로 발견하는 나의 브랜드 스타일 — 마크인포 프리즘의 상단 퍼널 체험형 콘텐츠

**v0.2.1** · 2026-09-04 · 16유형 · 12문항 · 모바일 우선

정적 파일만으로 동작합니다. 서버, 데이터베이스, 빌드 도구가 필요하지 않습니다.

---

## 폴더 구조

```
index.html                     랜딩 · 테스트 · 결과 (한 페이지 3화면)
site.webmanifest               홈 화면 추가용 앱 정보
version.json                   버전 정보
.nojekyll                      GitHub Pages 처리 비활성 (필수)
assets/
  css/lite.css                 스타일시트
  js/lite.js                   앱 로직 (라우팅 · 점수 · 공유 · 이벤트)
  data/lite-data.js            16유형 콘텐츠 + 12문항 + 축 정의
  img/brand/                   로고 · 파비콘
  img/og/                      공유 미리보기 이미지 17장 (유형별 16 + 기본 1)
README.md
```

## GitHub Pages 배포

1. 이 폴더의 **내용**을 저장소 루트(또는 `docs/`)에 커밋합니다
2. Settings → Pages → Source를 배포 브랜치로 지정합니다
3. `.nojekyll` 파일을 반드시 함께 올립니다 — 없으면 Jekyll이 `assets/` 일부를 무시할 수 있습니다

경로가 모두 상대경로이므로 `username.github.io/repo/` 같은 하위 경로에서도 그대로 동작합니다.

로컬에서 확인할 때는 폴더에서 아래를 실행하고 `http://localhost:8080` 으로 여세요. 파일을 직접 열면(`file://`) 결과 카드 이미지 저장이 막힙니다.

```
python3 -m http.server 8080
```

## 배포 전 설정해야 할 값

`index.html` 의 `</head>` 앞에 아래 블록을 넣으면 코드를 고치지 않고 설정할 수 있습니다.
기획서 12.2에서 "지금 확정해야 할 5가지"로 지목된 항목입니다.

```html
<script>
window.BSM_LITE_CONFIG = {
  prismUrl: 'https://…',   // 필수 · 로고 의뢰/문의 목적지
  fullUrl : '',            // 선택 · 전문 진단(풀버전) 주소. 비우면 링크가 숨습니다
  campaign: 'bsm16-lite',  // 선택 · 유입 캠페인 이름
  kakaoKey: ''             // 선택 · 카카오 JS 키. 비우면 카카오 버튼이 숨습니다
};
</script>
```

카카오 공유를 쓰려면 위 키와 함께 Kakao SDK 스크립트도 추가해야 합니다.

**프리즘으로 넘기는 파라미터** — CTA를 누르면 `result_code`, `result_name`, `campaign`, `source` 가 쿼리로 전달됩니다. 프리즘 문의 폼에서 이 값을 읽어 유형을 미리 채우면 고객이 결과를 다시 설명하지 않아도 됩니다.

## 분석 이벤트

`gtag` 또는 `dataLayer` 가 페이지에 있으면 자동으로 전송됩니다. 없으면 아무것도 하지 않습니다(로컬에서는 콘솔에만 출력).

| 이벤트 | 시점 | 속성 |
|---|---|---|
| `landing_view` | 랜딩 진입 | device, source, campaign |
| `test_start` | 시작 버튼 | cta_position (hero·footer·sticky) |
| `question_view` | 문항 노출 | question_id, step |
| `question_answer` | 선택 완료 | question_id, option, response_time |
| `test_resume` | 중단 후 복귀 | last_step |
| `result_view` | 결과 노출 | result_code, axis_scores, entry |
| `share_click` / `share_success` | 공유 시도 / 완료 | result_code, channel |
| `retest_click` | 다시 하기 | result_code |
| `prism_cta_click` | 프리즘 이동 | result_code, cta_position |

개인 식별 정보와 답변 원문은 어떤 이벤트에도 담기지 않습니다.

## 콘텐츠 수정

문항과 결과 문구는 화면 코드와 분리되어 있어 `assets/data/lite-data.js` 만 고치면 됩니다.

- `questions[]` — 문항 문구, 선택지, 축(`axis`), 각 선택지의 축 코드(`side`)
- `styles.<코드>` — 유형명·영문·보조 설명·키워드 3개·강점·추천(`do`)·주의(`dont`)·업종 예시·포인트색·팔레트
- `styles.<코드>.samples` — **예시 로고 슬롯**. 비어 있으면 유형의 추천 글꼴·색으로 만든 무드 샘플이 자동 표시됩니다. 권리 확인이 끝난 실제 로고가 준비되면 아래 형태로 채우면 그것이 우선 노출됩니다

```js
samples: [
  { src:'assets/img/logos/GBEC-01.png', name:'브랜드명', credit:'제공 · 사용 승인', bg:'#FFFFFF' }
]
```

유형명·보조 설명은 상위 퍼널(브랜드 스타일 매트릭스 16 v0.16.0)과 같은 원본을 씁니다. 한쪽만 고치면 두 서비스의 표현이 어긋나므로 함께 바꿔 주세요.

## 점수 로직

축마다 3문항이라 동점이 생기지 않습니다. 각 축에서 많이 선택된 쪽의 코드를 순서대로(G/L → B/S → E/R → C/M) 붙여 `GBEC` 같은 네 자리 코드를 만듭니다.

가능한 응답 조합 4,096가지를 전수 검증했습니다 — 정확히 16개 코드로 연결되고, 동점 0건, 코드당 256조합으로 균등합니다.

## 알아두실 점

- **결과 링크** `#/r/GBEC` 형태로 유형 코드만 담습니다. 답변·브랜드명은 URL에 들어가지 않습니다
- **진행 복구** 같은 브라우저 세션에서 6시간 안에는 이어서 진행할 수 있습니다. 결과를 본 뒤에는 진행 데이터를 지웁니다
- **공유 이미지** 유형별 OG 이미지가 미리 만들어져 있습니다. 유형 문구를 바꾸면 `assets/img/og/` 도 함께 갱신해야 합니다
- **접근성** 선택 상태를 색만으로 표시하지 않고 테두리·체크 아이콘을 함께 씁니다. 키보드 `1`·`2` 로 선택, `←` 로 이전 문항. 모션 줄이기 설정을 따릅니다
- **표현 원칙** 공개 화면에서 '진단'·'AI 분석'·'정확도' 같은 표현을 쓰지 않습니다. 결과 하단에 이 테스트의 범위를 명시해 전문 진단과 혼동되지 않게 했습니다
